# Space Dodger Starter — старт практикума

[English](README.en.md)

Стартовый проект темы 1 практикума **Space Dodger** Школы GameDev Creata Games,
подготовленный для GitHub-организации [creata-games](https://github.com/creata-games).
Здесь настроены редактор и MCP-мост, а главная сцена содержит только `Main` и камеру.
Нажми F5 — увидишь пустое поле. Игровые механики и свои материалы ты добавишь по ходу практикума.

- Практикум «Space Dodger» — в GameDev School Creata Academy
- [Посмотреть готовую игру](https://play.creata.games/game?id=space_dodger)
- Скачать проект: **Code → Download ZIP**, затем распакуй архив.

## Что нужно

| Инструмент | Для чего |
|---|---|
| [Godot 4.7.2 stable](https://godotengine.org/download/archive/4.7.2-stable/) | Обычная сборка с GDScript; проект использует 2D и Compatibility |
| [Claude Code](https://code.claude.com/docs/en/setup) | Помощник для кода; установи и выполни вход со своим доступом |
| [uv и uvx](https://docs.astral.sh/uv/getting-started/installation/) | Запуск Python-части Godot AI; обе команды должны быть доступны в терминале |
| Python 3 | Вспомогательные скрипты практикума; Python-средой моста управляет uv |

Для первой установки Python-части моста нужен интернет. Генераторы графики и звука
не нужны для открытия стартера: начать можно со своих материалов или геометрических заглушек.

Проверь команды (в Windows вместо `python3` обычно используется `py -3`):

```bash
godot --version
claude --version
uv --version
uvx --version
python3 --version
```

Команда `godot` должна запускать именно 4.7.2. Если её нет в PATH, используй полный
путь к исполняемому файлу редактора. Шаблоны экспорта понадобятся позднее, той же версии.

## Как открыть

1. Открой терминал в распакованной папке `space-dodger-starter`, рядом с `project.godot`.
2. Перед первым открытием отключи телеметрию моста и запусти редактор из этой папки.
   macOS/Linux:

   ```bash
   GODOT_AI_DISABLE_TELEMETRY=1 godot --editor --path .
   ```

   Windows PowerShell:

   ```powershell
   $env:GODOT_AI_DISABLE_TELEMETRY = "1"
   godot --editor --path .
   ```

   Если открываешь через менеджер проектов, сначала задай ту же переменную окружения
   для процесса Godot, затем **Import → project.godot → Import & Edit**.
3. В **Editor → Editor Settings** найди `godot_ai`: выключи `telemetry_enabled`,
   установи `mcp_client_scope = project`, оставь `allow_remote_hosts` пустым.
   Эти настройки редактора хранятся на твоём компьютере; `project.godot` их не задаёт.
4. Открой `scenes/main.tscn` в режиме **2D**. Нажми **F5**, проверь пустое поле,
   затем останови запуск кнопкой **■**. Камера находится в центре поля, `(960, 540)`.

Поле — 1920×1080, окно — 1280×720, растяжение — `canvas_items`, фильтр — Nearest.
Шины **Master**, **Music**, **SFX** уже настроены; аудиофайлов пока нет.

## Как подключить помощника

Godot AI **4.3.0** уже находится в `addons/godot_ai/` и включён в `project.godot`.
Редактор должен оставаться открытым с этим проектом.

1. Проверь **Project → Project Settings → Plugins → Godot AI**: плагин включён.
   Во вкладке **Godot AI** дождись **Server connected**.
2. В корне уже есть `.mcp.json` со scope проекта. Он запускает `uvx` из PATH,
   закрепляет `godot-ai==4.3.0`, использует локальные порты **8000** и **9500**
   и отключает телеметрию клиента. Ключи для моста не нужны. PyPI используется
   для установки пакета; само подключение к редактору работает локально.
3. В другом терминале из той же папки запусти `claude`. При первом запуске
   выполни вход, подтверди доверие к папке и подключение сервера `godot-ai` из `.mcp.json`.
4. Введи **`/mcp`**: сервер `godot-ai` должен быть **connected**. Попроси:

   > Какие инструменты godot-ai тебе доступны? Прочитай дерево открытой сцены
   > и сними кадр пустой сцены, ничего не меняя.

   Ожидаемое дерево сцены: `Main → Camera`. Для кадра игры запусти F5;
   перед изменением сцены останови игру. Помощник прочитает правила из `CLAUDE.md`.

Если связи нет, проверь `uvx --version`, открытый редактор и свободные порты 8000/9500,
затем перезапусти `claude` из корня проекта. При других портах сверь значения во вкладке
Godot AI и в `.mcp.json`. Кнопка **Configure** необязательна: конфигурация уже приложена.
Если используешь её, сначала проверь scope `project` и запускай редактор из папки проекта.
При недоступном MCP можно править файлы с помощником и проверять результат вручную в Godot.

## Что внутри

| Путь | Назначение |
|---|---|
| `project.godot`, `scenes/main.tscn` | Настройки и пустая сцена с камерой |
| `default_bus_layout.tres` | Music/SFX направлены в Master |
| `addons/godot_ai/` | MCP-мост 4.3.0, включая исходную MIT-лицензию |
| `.mcp.json`, `CLAUDE.md` | Локальное подключение и правила помощника |
| `assets/sprites/`, `assets/sprites/obstacles/`, `assets/audio/`, `assets/fonts/` | Пустые папки с `.gitkeep` для твоих материалов |
| `scripts/` | Пустая папка для твоего кода |
| `data/obstacles.json` | Формат каталога: массив `obstacles`, одна выключенная запись-пример |
| `tests/smoke_test.gd` | Заглушка на встроенном SceneTree: проверяет загрузку сцены и наличие камеры |

В каталоге `sprite` и `game.behavior` пока пустые, `game.enabled = false`, `weight = 0`.
На шаге с препятствиями замени пример своими данными: добавь PNG в
`assets/sprites/obstacles/`, укажи путь `res://assets/sprites/obstacles/…`, заполни
описание, зону касания и параметры поведения. После реализации загрузчика и поведения
можно включить запись и назначить ей вес. Сейчас каталог ничем не загружается.
Пути в лабораторной вида `Assets/Sprites/` здесь заменены на `assets/sprites/`;
используй регистр папок этого проекта.

Действия Input Map уже созданы. Они заработают в игре после реализации механик:

| Действие | Клавиши |
|---|---|
| `move_up`, `move_left`, `move_down`, `move_right` | WASD и стрелки |
| `shoot` | Space / J |
| `dash` | Shift / K |
| `pause` | Esc / P |
| `restart` | R |

## Проверка и начало темы 1

В терминале из корня проекта:

```bash
godot --headless --path . --editor --import
godot --headless --path . -s tests/smoke_test.gd
```

Ожидаемый результат второй команды: `OK: starter scene loaded. Gameplay checks are still TODO.`
Это подтверждает только загрузку стартовой сцены. Проверки игровых механик ты добавишь позже.

До темы 1 проверь версии, запуск F5, `/mcp`, дерево сцены и кадр. Прочитай тему и рубрику,
создай `ЖУРНАЛ.md` для своих решений и `ИИ-ЖУРНАЛ.md` для работы помощника и своих проверок.
Сохрани исходное состояние в своей истории изменений. Затем подготовь свои спрайты
или заглушки и согласуй с помощником план первого игрового цикла по заданию темы.
